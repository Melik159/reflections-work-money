# Contribution, différences et valeur analytique

[Matrice](contribution_matrix.csv) · [21 comparaisons conceptuelles](concept_comparisons.md) · [24 CORE](claim_comparisons.md) · [32 scénarios monétaires](money_scenario_comparisons.md) · [Candidats](candidate_contributions.md) · [Incertitudes historiques](unresolved_novelty.md) · [Risques](false_novelty_risks.md) · [Distinctions utiles](underappreciated_distinctions.md) · [Littérature](literature.md).

La matrice contient21 entrées conceptuelles et24 claims, soit45 lignes qui ne sont **pas45 contributions indépendantes**. Les nombres de la synthèse sont décomptés séparément par population et statut principal; le statut historique est un autre axe.

KNOWN_EQUIVALENT signifie équivalence dans le périmètre précisé, non équivalence de toutes les relations associées. DISTINCT_FORMAL_RESTRICTION signifie une restriction non impliquée par les comparateurs nommés, non inédit historique, résultat vrai ou prédiction empiriquement identifiée. Les quatre évaluations de valeur restent séparées, sans moyenne numérique.

Les comparaisons sont des INTERPRETATION. Les citations et définitions originales sont conservées, notamment pour Money, Work et Utility. Cette passe ne collecte pas de données nouvelles et ne mesure aucune de ces grandeurs par substitution silencieuse.
