# RQ-07.02 — Une transaction ou décision non neutre entre acteurs implique-t-elle une création globale ?

Types : FORMAL_TEST. Statut du protocole : DESIGNED_FIRST_PASS.

CONSISTENCY_TEST : deux agents puis intermédiaire, bilans avant/après, prix/qualité/coût séparés. Incompatible avec création par transfert seul : bilan global inchangé malgré gain individuel. Données futures : transactions appariées.

Explication concurrente : Rente, surplus d’échange et transfert comptable peuvent évoluer différemment.
